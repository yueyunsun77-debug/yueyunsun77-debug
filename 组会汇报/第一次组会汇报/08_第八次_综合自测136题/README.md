## 推荐顺序

先读输入输出文档，再对照PPT读逐字稿，最后做问答练习。先练30道必练，不必为了覆盖全部题目而牺牲完整试讲。

新增自测先练 [Q121信息泄漏](03_老师提问120题与参考答案.md#q121)、[Q123手算注意力](03_老师提问120题与参考答案.md#q123)、[Q130读实验表](03_老师提问120题与参考答案.md#q130)、[Q132维度衔接](03_老师提问120题与参考答案.md#q132)、[Q134词元ID与向量](03_老师提问120题与参考答案.md#q134)。其余进阶与挑战题按精力选做。新增数值与情境均为教学构造，不是论文额外报告的实验。

一次完整练习可以这样安排：

- 约15分钟：完整试讲，计时并记录卡点。
- 约20分钟：优先练Q011、Q012、Q017、Q025、Q031、Q033、Q046、Q067、Q081、Q104。
- 约15分钟：回看卡点并用自己的话重讲，不照抄未理解的答案。

## 数字与版本口径

统一使用NIPS 2017会议版PDF。PPT第12页为测试集结果，第13页为开发集变体，二者不能直接混用。训练FLOPs为原文估算，不能直接转成耗时倍数。

讲稿与题库中的数值例子属于教学构造；论文结果来自作者报告。没有做过的训练复现或实验，不应照着答案表述成自己已经完成。
