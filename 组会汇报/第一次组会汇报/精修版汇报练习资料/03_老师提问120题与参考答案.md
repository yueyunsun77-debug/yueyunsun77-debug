## A｜研究背景与论文贡献

原文定位：§1–2；§4；§7；[打开相关PDF页面](https://proceedings.neurips.cc/paper_files/paper/2017/file/3f5ee243547dee91fbd053c1c4a845aa-Paper.pdf#page=1)。

<a id="q001"></a>

### Q001｜用一句话说明，这篇论文做了什么？【必练】

**参考口答：** 它提出Transformer：在编码器—解码器框架中，以注意力主导序列位置之间的信息交互，并在机器翻译任务上验证质量与训练效率。这里汇报的是2017年的原始模型。

<a id="q002"></a>

### Q002｜作者真正想解决什么问题？【必练】

**参考口答：** 主要是减少循环式表示计算的顺序依赖，缩短远位置之间的信息传播路径，同时保留足够的上下文表示能力。目标是兼顾翻译质量与训练效率，不是单独追求更高指标。

<a id="q003"></a>

### Q003｜为什么第一次论文汇报选择一篇2017年的论文？【常见】

**参考口答：** 因为它是理解Transformer机制的起点，研究问题、架构和实验相对完整。先掌握原始模型，有助于辨别后续改进改变了什么；选择它是为了建立基础，不是把它当成最新成果。

<a id="q004"></a>

### Q004｜以前的RNN翻译模型怎样工作？【常见】

**参考口答：** 循环网络沿源位置逐步计算隐藏状态，解码器根据目标前缀生成目标。带注意力的模型还会根据当前解码状态，对源句表示加权选择；但源表示的循环计算依赖仍然存在。

<a id="q005"></a>

### Q005｜卷积序列模型已经能并行，为什么还需要Transformer？【常见】

**参考口答：** 局部卷积虽可并行计算位置特征，但远位置的联系通常需要通过多层扩大感受范围。全局自注意力允许一层内直接访问所有可见位置，改变了交互路径；是否更有效仍需实验判断。

<a id="q006"></a>

### Q006｜注意力机制是这篇论文首次提出的吗？【必练】

**参考口答：** 不是。论文明确讨论了先前已有注意力和自注意力研究。它的重要贡献是把注意力放在序列交互的主体位置，配合多头等设计构成完整Transformer架构。

<a id="q007"></a>

### Q007｜本文的创新应怎样分层讲？【必练】

**参考口答：** 先讲核心架构：用自注意力替代循环或卷积作为交互骨干；再讲缩放点积与多头设计；最后讲显式位置编码等配套机制。前馈网络、残差、归一化等属于已有组件，不能一概声称由本文发明。

<a id="q008"></a>

### Q008｜标题为什么叫Attention Is All You Need，网络里不是还有其他模块吗？【常见】

**参考口答：** 标题强调不再依赖循环或卷积来建立主要的序列位置联系。实际模型仍包含嵌入、位置编码、前馈网络、残差和层归一化，所以不能把标题解释成整个网络只剩一个注意力算子。

<a id="q009"></a>

### Q009｜已有注意力也能直接查询源句，本文的“短路径”新在哪里？【常见】

**参考口答：** 要区分源—目标对齐与同一序列内部的表示计算。已有循环模型可以在解码时关注整个源句，但源隐藏状态仍依赖循环生成。本文把自注意力用于源序列和目标前缀内部的表示更新。

<a id="q010"></a>

### Q010｜这篇论文是否证明Transformer在任何任务上都最好？【常见】

**参考口答：** 没有。它提供了具体任务、数据与配置下的理论动机和实验证据。应说“在论文设置下取得了强结果”，不能将当时的翻译结果外推为所有任务或今天的最优性能。


## B｜输入、输出与任务边界

原文定位：§3；§5–6；[打开相关PDF页面](https://proceedings.neurips.cc/paper_files/paper/2017/file/3f5ee243547dee91fbd053c1c4a845aa-Paper.pdf#page=2)。

<a id="q011"></a>

### Q011｜整个模型的输入是什么？训练和推理是否相同？【必练】

**参考口答：** 训练输入是源词元序列、右移后的真实目标序列及适用的掩码；真实下一词另作监督标签。推理输入是源序列与已经生成的目标前缀，因为未来目标还未知。

<a id="q012"></a>

### Q012｜模型的输出到底是一个词、一个向量，还是一句话？【必练】

**参考口答：** 不同层次不同：解码器先产生隐藏向量，输出层产生词表logits或概率分布，解码程序再逐步选择词元，最终得到完整译文。不能把神经网络一次前向的结果与应用最终输出混为一谈。

<a id="q013"></a>

### Q013｜既然目标句已经作为训练输入，模型是不是提前知道答案？【常见】

**参考口答：** 目标输入先右移，并用因果掩码限制可见性。预测第t个目标时，只能读取此前真实目标词元，而不能读取该位置或之后的待预测标签，所以不是把当前答案直接喂进去。

<a id="q014"></a>

### Q014｜原始文本能直接送进Transformer吗？【常见】

**参考口答：** 通常先进行分词或子词切分，再用词表映射成离散ID，然后查嵌入矩阵得到连续向量。原文英德使用子词编码，因此“词元”不一定对应完整单词；网络并不是直接处理未经编码的字符串。

<a id="q015"></a>

### Q015｜源句与目标句的长度必须相同吗？【常见】

**参考口答：** 不必相同。源长度可以是n，目标长度是m，交叉注意力的关系矩阵形状就是m乘n。每个目标查询可以从所有有效源位置汇总信息，不要求位置一一对应。

<a id="q016"></a>

### Q016｜BOS、EOS和PAD各起什么作用？【常见】

**参考口答：** BOS常用作开始生成的起始标记，EOS用于指示结束，PAD用于把不同长度样本补到可组成batch的长度。具体符号和ID依实现而定，示意中的名字不是原文规定的唯一固定名称。

<a id="q017"></a>

### Q017｜请用例子说明什么叫“目标右移一位”。【必练】

**参考口答：** 若目标为“Ich mag Bücher”，示意解码输入为“BOS Ich mag Bücher”，标签为“Ich mag Bücher EOS”。预测Ich时只见BOS，预测mag时可见BOS和Ich，后面依次类推。输入与标签长度可以相同，但对应位置的元素不同。

<a id="q018"></a>

### Q018｜decoder input和label有什么区别？【常见】

**参考口答：** decoder input是模型用于条件预测的已知前缀，label是用于计算当前预测误差的真实下一词。实现中两者常由同一目标序列错开一位构造，但用途不同；label不应直接参与当前待预测位置的特征计算。

<a id="q019"></a>

### Q019｜下一词的概率分布怎样变成完整译文？【常见】

**参考口答：** 解码程序从分布中选择或搜索候选词元，把结果追加到前缀，再继续前向计算。原文采用束搜索，并使用长度惩罚；到EOS或其他停止条件后，词元序列经反分词得到文本。

<a id="q020"></a>

### Q020｜编码器输出Z是什么？为什么它还不是译文？【常见】

**参考口答：** Z是每个源位置的上下文特征，base形状可写成B乘n乘512。它保留源序列位置结构，供解码器查询；还没有经过目标词表输出层，也没有执行逐步生成，因此不是目标词元序列。


## C｜架构与信息流

原文定位：§3.1；§3.2.3；Figure 1；[打开相关PDF页面](https://proceedings.neurips.cc/paper_files/paper/2017/file/3f5ee243547dee91fbd053c1c4a845aa-Paper.pdf#page=3)。

<a id="q021"></a>

### Q021｜编码器和解码器分别承担什么职责？【必练】

**参考口答：** 编码器把源句转换为上下文表示；解码器结合已知目标前缀与源句表示，产生每个目标位置的隐藏状态，继而预测下一词。源上下文和目标上下文在交叉注意力中汇合。

<a id="q022"></a>

### Q022｜六层“相同层”是不是共用同一套参数？【常见】

**参考口答：** 原文所说相同主要指结构相同，层与层之间通常使用各自独立的参数。不能把六层堆叠理解成反复调用完全共享权重的同一层；共享是否采用需要单独设计与说明。

<a id="q023"></a>

### Q023｜为什么编码器每层两个子层，而解码器每层三个？【常见】

**参考口答：** 编码器每层包含自注意力与逐位置前馈网络。解码器还需要从源句获取信息，所以在掩码自注意力和前馈网络之间增加编码器—解码器注意力；各子层都配残差和归一化。

<a id="q024"></a>

### Q024｜编码器可以同时看到源句后面的词，为什么不算泄漏？【常见】

**参考口答：** 标准翻译任务的整个源句在预测译文前已知，因此编码器可以访问全部有效源位置。需要隐藏的是尚未知晓的未来目标，而不是完整已知源句；在线流式翻译是另一种任务设置。

<a id="q025"></a>

### Q025｜三种注意力的Q、K、V分别来自哪里？【必练】

**参考口答：** 编码器自注意力三者来自源表示；解码器掩码自注意力三者来自右移目标表示；交叉注意力中Q来自当前解码器表示，K、V来自编码器输出。它们都经过对应的可学习投影。

<a id="q026"></a>

### Q026｜交叉注意力中的Query具体是哪一个解码状态？【常见】

**参考口答：** 它来自该解码层已经处理了可见目标前缀的表示，即掩码自注意力及相应残差归一化之后的状态，再经Query投影。它不来自编码器，也不是未来真实目标的表示。

<a id="q027"></a>

### Q027｜每个解码层使用哪个编码器输出？【常见】

**参考口答：** 原始架构中，各解码层的交叉注意力都使用最终编码器堆叠的输出作为源侧表示，再通过各层自己的投影得到K、V。不是第一个解码层只查询第一个编码层、第二个只查询第二个。

<a id="q028"></a>

### Q028｜模型维度为什么在子层之间保持一致？【常见】

**参考口答：** 残差相加要求对应张量形状匹配，统一模型维度也便于堆叠与模块连接。base的子层输入输出维度为512，但内部可以改变维度，例如每头64、FFN中间2048，之后投影回512。

<a id="q029"></a>

### Q029｜位置编码是在每一层都重新相加吗？【常见】

**参考口答：** 原文在编码器和解码器堆叠的底部，将位置编码加到输入嵌入上。后续层继续变换含位置信息的表示，不应把Figure 1的六层标记理解为每层都重复整个输入嵌入流程。

<a id="q030"></a>

### Q030｜Linear和Softmax输出层怎样工作？【常见】

**参考口答：** 解码器每个目标位置的隐藏向量先通过线性映射，得到目标词表大小的logits，再通过Softmax得到词概率。它与注意力中的Softmax不同：输出Softmax对词表归一化，注意力Softmax对可见键位置归一化。


## D｜QKV与缩放点积注意力

原文定位：§3.2.1；Equation (1)；[打开相关PDF页面](https://proceedings.neurips.cc/paper_files/paper/2017/file/3f5ee243547dee91fbd053c1c4a845aa-Paper.pdf#page=4)。

<a id="q031"></a>

### Q031｜Q、K、V怎样用自己的话解释？【必练】

**参考口答：** Q是当前查询，K用于与查询匹配，V是匹配后实际汇总的信息。先根据Q与各K算权重，再对各V加权求和；这些是可学习特征角色，不是人工建立的固定词典查询表。

<a id="q032"></a>

### Q032｜Q、K、V是三份独立的原始数据吗？【常见】

**参考口答：** 在自注意力中，它们通常来自同一输入X，分别乘不同的可学习投影矩阵。交叉注意力中，查询来自目标侧表示，键和值来自源侧表示，所以不能一概说三者总来自同一数据。

<a id="q033"></a>

### Q033｜请完整解释注意力公式的四步。【必练】

**参考口答：** 第一步计算QK转置的匹配分数；第二步除以根号dk并加入适用的掩码；第三步对每个查询的有效键分数做Softmax；第四步用权重矩阵乘V，得到各查询的输出特征。

<a id="q034"></a>

### Q034｜Softmax究竟沿哪个方向归一化？【常见】

**参考口答：** 对每个查询，沿键位置这一维归一化。若分数矩阵为Lq乘Lk，就是每一行在有效键上的权重和为1。不要把它误做成所有查询一起归一化，也不要与最终词表Softmax混淆。

<a id="q035"></a>

### Q035｜为什么使用Softmax，而不是直接把分数当权重？【常见】

**参考口答：** Softmax把任意实数分数转换为非负、可归一化的相对权重，更便于稳定地对Value汇总。原始点积可以为负，也没有固定尺度；直接使用会改变模型的数学性质，不能视为同一个注意力计算。

<a id="q036"></a>

### Q036｜为什么除以√dk？【必练】

**参考口答：** 在分量独立、均值为零、方差为一的简化假设下，q与k的点积方差为dk。除以根号dk后方差回到约一，减轻维度增大导致分数幅值过大、Softmax饱和且梯度变小的风险。这是尺度控制，不是消除全部训练问题。

<a id="q037"></a>

### Q037｜base里缩放因子到底用√64、√512还是√8？【常见】

**参考口答：** 用该头的键维度dk，所以base每头dk=64，除以√64，也就是8。512是模型维度，8也是头数，但不能因为它们恰好相关就把定义混淆；big每头仍可为64。

<a id="q038"></a>

### Q038｜为什么要给Q和K使用不同投影，直接令它们相同可以吗？【常见】

**参考口答：** 不同投影让“提出查询”与“提供匹配特征”具有不同可学习角色，表达更灵活。强行共享或令它们相同可以构造一个变体，但增加了约束，不能假定它与原始模型等价或效果相同。

<a id="q039"></a>

### Q039｜自注意力的关系矩阵一定是对称的吗？【拓展】

**参考口答：** 不一定。不同WQ与WK使QK转置通常不对称；即使原始分数恰好对称，逐行Softmax的归一化因子也可能不同，最终权重仍未必对称。因果掩码还会进一步引入方向性。

<a id="q040"></a>

### Q040｜权重最大的那个位置就一定贡献最大吗？【常见】

**参考口答：** 加权贡献还取决于Value向量的数值及后续变换。例如某位置权重很大但Value接近零，直接汇总贡献仍可能较小。因此不能仅按权重大小断言最终预测的因果重要性。


## E｜张量维度与数值练习

原文定位：§3.2.1–3.2.2；第6页教学例子；[打开相关PDF页面](https://proceedings.neurips.cc/paper_files/paper/2017/file/3f5ee243547dee91fbd053c1c4a845aa-Paper.pdf#page=4)。

<a id="q041"></a>

### Q041｜最一般的单头注意力输入输出维度是什么？【必练】

**参考口答：** Q是Lq乘dk，K是Lk乘dk，V是Lk乘dv。分数与权重矩阵都是Lq乘Lk，最终输出是Lq乘dv。输出位置数量由查询长度决定，输出特征维度由Value维度决定。

<a id="q042"></a>

### Q042｜如果base输入有5个位置，一个头的各张量多大？【常见】

**参考口答：** 省略batch时，X为5乘512，单头Q、K、V为5乘64，QK转置为5乘5，乘V后得到5乘64。八头拼接为5乘512，再经过输出投影。

<a id="q043"></a>

### Q043｜加入batch与head维度后，编码器注意力权重是什么形状？【常见】

**参考口答：** 一种常见布局是B乘h乘n乘n，base的h为8。逻辑含义是每个样本、每个头都有一个查询位置对键位置的权重矩阵；实现可以临时合并维度，不能只凭内存布局判断含义。

<a id="q044"></a>

### Q044｜交叉注意力的矩阵为什么是m乘n，不是n乘n？【常见】

**参考口答：** 目标侧有m个查询，源侧有n个键和值，所以每个目标位置都可以查询n个源位置。权重为m乘n，输出仍有m个位置；base每头输出m乘64。

<a id="q045"></a>

### Q045｜单头的投影矩阵与输出投影分别有多大？【常见】

**参考口答：** base中WQ、WK、WV分别可为512乘64。八头拼接后总维度为512，WO为512乘512。一般公式中WO的形状是h·dv乘dmodel，不必在所有变体里都强制相同维度关系。

<a id="q046"></a>

### Q046｜PPT第6页的输出(0.335,0.755)怎样算出来？【必练】

**参考口答：** 缩放分数为[1,2,0]，Softmax约为[0.2447,0.6652,0.0900]。分别乘(1,0)、(0,1)、(1,1)再相加，第一维为0.2447+0.0900，第二维为0.6652+0.0900，所以约为(0.335,0.755)。

<a id="q047"></a>

### Q047｜这组示例分数能来自一致的Q与K吗？【常见】

**参考口答：** 可以。取dk=2，q=(1,0)，三个k分别为(√2,0)、(2√2,0)、(0,1)。点积后除以√2，就得到[1,2,0]。这是人为构造的数学示例，不是论文的真实注意力。

<a id="q048"></a>

### Q048｜分数为负会不会导致负概率？Softmax减去最大值又是什么？【常见】

**参考口答：** 不会，指数结果为正，归一化后得到非负概率。实际计算常先给同一行减去最大分数，利用Softmax对统一平移不变来减少指数溢出；这不会改变数学上的权重。

<a id="q049"></a>

### Q049｜点积注意力就是余弦相似度吗？【拓展】

**参考口答：** 不是。余弦相似度需要除以两个向量的范数；原文是点积除以√dk，没有逐向量范数归一化。点积同时受方向与幅值影响，所以不能把两者直接画等号。

<a id="q050"></a>

### Q050｜注意力输出一定是输入向量的凸组合吗？【拓展】

**参考口答：** 在标准Softmax加权这一阶段，单头输出是Value向量的凸组合，因为权重非负且和为一。但Value已被投影，后续还有WO、残差与FFN，所以完整Transformer输出并不必然是原始词嵌入的凸组合。


## F｜多头注意力

原文定位：§3.2.2；Figure 2；Table 3(A)；[打开相关PDF页面](https://proceedings.neurips.cc/paper_files/paper/2017/file/3f5ee243547dee91fbd053c1c4a845aa-Paper.pdf#page=4)。

<a id="q051"></a>

### Q051｜多头注意力具体做了哪几件事？【必练】

**参考口答：** 各头用独立的WQ、WK、WV投影输入，分别做注意力，之后拼接各头输出，再通过WO融合。多头的关键在于可学习子空间不同，不是把同一个结果简单复制多次。

<a id="q052"></a>

### Q052｜为什么用8个头，8就是最优的吗？【常见】

**参考口答：** 8是原文base配置，不是适用于所有任务的理论最优值。原文变体中8头与16头开发集BLEU相同，更多头也会下降；具体头数需要结合模型维度、任务与资源选择。

<a id="q053"></a>

### Q053｜每个头只读取输入向量中固定的一小段吗？【常见】

**参考口答：** 按原文公式，每个头的投影都可以读取完整dmodel维输入，再映射到较小子空间。实现常先做一次大的线性投影再reshape，但这不等于先把原始输入硬切成互不交流的小段。

<a id="q054"></a>

### Q054｜每头64维是怎样来的？【常见】

**参考口答：** 原文base令dk=dv=dmodel/h，即512除以8得到64。每个头仍处理整个序列，只是键和值的特征维度较小，不能把64解释为只处理64个词。

<a id="q055"></a>

### Q055｜为什么拼接，不直接把多个头平均？【常见】

**参考口答：** 拼接先保留不同头的通道，WO再学习如何组合，较少提前把不同表示混在一起。直接平均会改变输出结构与信息融合方式，是一个不同设计，不能假设与原模型等价。

<a id="q056"></a>

### Q056｜输出投影WO有什么作用？【常见】

**参考口答：** 它把拼接后的各头特征进行可学习的线性融合，并映射到模型维度，便于后续子层与残差连接。即使拼接后已经是512维，WO仍然提供通道间混合，而不是纯粹为了凑维度。

<a id="q057"></a>

### Q057｜能不能说第一个头负责语法，第二个头负责语义？【常见】

**参考口答：** 不能预先这样指定。不同头可能在训练后呈现不同模式，但分工需通过实际分析判断，而且可能重叠。PPT中的头内矩阵是教学示意，不能作为真实模型头分工的证据。

<a id="q058"></a>

### Q058｜各个头是否独立？会不会学出重复模式？【拓展】

**参考口答：** 各头有独立投影参数和注意力计算，但共享输入、输出融合与最终训练目标，所以不意味着统计独立。它们可能学到相似或冗余模式；原文设计并不保证每个头都形成完全不同的语义角色。

<a id="q059"></a>

### Q059｜8个头是不是比1个头贵8倍？【拓展】

**参考口答：** 在固定dmodel且每头维度按dmodel/h缩小时，核心计算与参数规模不会简单增加八倍，原文称成本与全维单头相近。但头数会影响权重矩阵存储、实现开销和并行效率，不能声称完全零成本。

<a id="q060"></a>

### Q060｜模型维度不能被头数整除时还能实现多头吗？【拓展】

**参考口答：** 常见实现固定每头维度为dmodel/h并reshape，因此要求整除。更一般的数学定义可以独立选dk、dv，再用WO投影回dmodel；但需要相应调整实现，不能直接套用要求整除的库配置。


## G｜位置编码与掩码

原文定位：§3.2.3；§3.5；Table 3(E)；[打开相关PDF页面](https://proceedings.neurips.cc/paper_files/paper/2017/file/3f5ee243547dee91fbd053c1c4a845aa-Paper.pdf#page=5)。

<a id="q061"></a>

### Q061｜为什么Transformer还需要位置编码？【必练】

**参考口答：** 内容匹配本身不能给编码器提供完整的绝对或相对位置线索。原文取消循环和卷积后，在底部嵌入上加入显式位置编码，让网络能够利用词序；仅有相同词内容并不足以表达不同排列。

<a id="q062"></a>

### Q062｜正弦、余弦位置编码的公式与变量含义是什么？【拓展】

**参考口答：** 原文为PE(pos,2i)=sin(pos/10000^(2i/dmodel))，PE(pos,2i+1)=cos(pos/10000^(2i/dmodel))。pos是位置，i是成对维度的索引，不是第i个词；不同维度对应不同频率。

<a id="q063"></a>

### Q063｜为什么把位置编码相加，而不是再加一个位置维度？【常见】

**参考口答：** 原文让位置编码与词嵌入同为dmodel维，再逐元素相加，保持残差与后续层的维度。拼接或附加单个标量是其他设计，需要重新考虑投影和尺度，不能当作原文操作。

<a id="q064"></a>

### Q064｜学习式位置嵌入与固定正余弦有什么区别？【常见】

**参考口答：** 学习式将位置向量作为参数，训练过程中更新；固定正余弦按公式生成，不需要学习这些位置参数。原文比较两者结果接近，因此不能仅凭本文断言正余弦必然更好。

<a id="q065"></a>

### Q065｜正余弦能计算任意位置，所以一定能处理任意长句吗？【拓展】

**参考口答：** 不能这样推出。能构造未见位置的向量，不等于模型在未训练过的长度上一定可靠；注意力成本、训练分布和模型学到的模式仍会限制效果。原文对外推是设计动机，不能说成普遍保证。

<a id="q066"></a>

### Q066｜不加位置编码的Transformer是不是完全不懂顺序？【拓展】

**参考口答：** 对不带位置线索、全局可见的自注意力，置换输入通常使输出按相同方式置换，即具有置换等变性质。但因果掩码本身含有方向结构，所以不应把整个带掩码解码器笼统称为完全顺序无感。原文仍采用显式位置编码。

<a id="q067"></a>

### Q067｜为什么目标右移后还要加掩码？只右移够不够？【必练】

**参考口答：** 只右移而不加因果掩码，某个位置仍可能读取右侧已经放入的未来目标输入，从而泄漏待预测答案。右移对齐输入与下一词标签，掩码限制各查询的可见位置，两者配合才构成正确训练条件。

<a id="q068"></a>

### Q068｜掩码为什么允许看对角线？这不就是看到当前答案吗？【必练】

**参考口答：** 当前解码输入已经右移。预测第t个标签时，该输入位置放的是前一个已知词，因此允许看自身输入位置是合理的。要区分输入位置索引与原始目标标签的词元索引。

<a id="q069"></a>

### Q069｜掩码是在Softmax前还是之后处理？为什么不是把分数置零？【常见】

**参考口答：** 通常在Softmax前把非法位置的分数设为负无穷或足够小，使其归一化权重为零。直接把非法分数设为零仍会得到exp(0)，并不能屏蔽；不同库的布尔掩码语义也要核对。

<a id="q070"></a>

### Q070｜因果掩码、padding掩码和交叉注意力掩码有什么区别？【常见】

**参考口答：** 因果掩码屏蔽未来目标位置；padding掩码屏蔽补齐出来的无效位置。标准翻译的交叉注意力可以看全部有效源句，一般不对源位置加目标式下三角限制，但仍需处理源padding。


## H｜前馈网络、残差与归一化

原文定位：§3.1；§3.3；§3.4；Table 3；[打开相关PDF页面](https://proceedings.neurips.cc/paper_files/paper/2017/file/3f5ee243547dee91fbd053c1c4a845aa-Paper.pdf#page=5)。

<a id="q071"></a>

### Q071｜有了注意力，为什么还要前馈网络？【常见】

**参考口答：** 注意力主要在位置之间混合信息，逐位置FFN进一步变换每个位置的特征通道。它提供两层线性变换及中间激活，与跨位置交互互补；不能说注意力完全没有非线性，因为Softmax本身就是非线性的。

<a id="q072"></a>

### Q072｜原文FFN的公式和维度是什么？【常见】

**参考口答：** FFN(x)=max(0,xW1+b1)W2+b2，中间激活是ReLU。base维度为512到2048再回到512；big的中间维度为4096，模型维度为1024。不要把后续常见激活或门控结构当成原文配置。

<a id="q073"></a>

### Q073｜FFN在不同位置之间共享参数吗？不同层也共享吗？【常见】

**参考口答：** 同一层内，FFN对各位置使用同一组参数并独立应用；不同层使用各自参数。位置独立不等于位置表示不含上下文，因为输入FFN前已经经过注意力交互。

<a id="q074"></a>

### Q074｜原始Transformer是Pre-LN还是Post-LN？【必练】

**参考口答：** 原文是Post-LN，即LayerNorm(x+Sublayer(x))：先做子层计算，再与输入残差相加，之后归一化。某些后续实现把归一化放到子层前，不能把那种顺序直接当成2017年的原始结构。

<a id="q075"></a>

### Q075｜残差连接为什么要求输入输出维度相同？它一定保证不梯度消失吗？【常见】

**参考口答：** 逐元素相加需要形状匹配，所以子层一般投影回模型维度。残差为信息与梯度提供直接通路，有助于训练深层网络，但不能说它单独保证任何配置都不会梯度消失或训练失败。

<a id="q076"></a>

### Q076｜LayerNorm与BatchNorm有什么区别？【常见】

**参考口答：** 典型Transformer的LayerNorm对每个位置的特征维度做归一化，不依赖其他样本的batch统计；BatchNorm通常利用batch等维度的统计。LayerNorm适合变长序列和逐步解码，但不能把两者所有实现都简化成同一种轴规则。

<a id="q077"></a>

### Q077｜LayerNorm具体归一化哪些数，是否有可学习参数？【拓展】

**参考口答：** 在常见B乘L乘dmodel表示中，对单个样本、单个位置的dmodel个特征计算均值和方差，再使用可学习的缩放与偏移参数。它不是把整句话的所有词一起平均，也不是把所有样本混成同一统计。

<a id="q078"></a>

### Q078｜如果去掉FFN，只剩注意力，会怎样？【拓展】

**参考口答：** 这会形成新的模型变体。可以从机制上说减少了逐位置通道变换，但原文并没有给出足够证据让我报告任意删减配置的具体性能。若要判断效果，应在控制预算与训练设置后实际做消融，而不是猜一个下降幅度。

<a id="q079"></a>

### Q079｜嵌入权重是否共享？为什么还会出现乘√dmodel？【拓展】

**参考口答：** §3.4说明原文在两类嵌入层与输出前线性变换之间采用权重共享，并把嵌入乘√dmodel。共享需要词表及维度安排兼容；嵌入缩放与注意力除以√dk是不同位置的操作，不能混成同一个因子。

<a id="q080"></a>

### Q080｜base和big具体有什么差别，参数量是多少？【拓展】

**参考口答：** 按会议版Table 3，base为6层、512维、2048维FFN、8头，约65M参数；big为6层、1024维、4096维FFN、16头，约213M。参数量与词表和共享方式有关，引用时应注明对应论文配置，不能泛指所有Transformer。


## I｜训练、推理与实现

原文定位：§5；§6.1；通用实现解释已按原文架构限定；[打开相关PDF页面](https://proceedings.neurips.cc/paper_files/paper/2017/file/3f5ee243547dee91fbd053c1c4a845aa-Paper.pdf#page=7)。

<a id="q081"></a>

### Q081｜为什么训练能并行，推理却要一个词一个词生成？【必练】

**参考口答：** 训练时完整真实目标已知，可以构造右移输入并用掩码同时计算各位置，通常称teacher forcing。推理没有未来真值，必须把已经生成的词作为下一步条件；并行训练不自动消除自回归生成依赖。

<a id="q082"></a>

### Q082｜交叉熵损失的输入是什么？代码里要不要先做Softmax？【必练】

**参考口答：** 概念上用预测分布与真实标签计算负对数似然；实际库中的CrossEntropyLoss常直接接收logits，内部合并稳定的log-softmax运算。应核对接口，避免先Softmax再把概率当logits传入，或重复归一化。

<a id="q083"></a>

### Q083｜标签平滑是什么？原文用多少？【拓展】

**参考口答：** 它把完全one-hot的训练目标改为更平滑的目标分布，减轻模型对唯一类别过度自信。原文平滑系数为0.1；概率怎样分配给其他类别要看具体实现，不能把某一种分配约定说成所有实现唯一标准。

<a id="q084"></a>

### Q084｜原文采用什么优化器和学习率计划？【拓展】

**参考口答：** 使用Adam，β1=0.9、β2=0.98、ε=10^-9。学习率按dmodel^-0.5乘min(step^-0.5, step·warmup^-1.5)变化，warm-up为4000步，即先线性上升，再按步数平方根的倒数衰减。

<a id="q085"></a>

### Q085｜Dropout放在哪里，比例是多少？【拓展】

**参考口答：** §5.4描述对子层输出、在残差相加前施加Dropout，也对嵌入与位置编码之和施加。base的比例为0.1；big还需区分任务配置，不能把一个比例笼统用于全部模型。原文英法big使用0.1而非通常big配置的0.3。

### Q086｜padding会不会影响训练损失？【常见】

### Q087｜原文推理用贪心还是束搜索？重要设置有哪些？【拓展】

<a id="q088"></a>

### Q088｜beam search一定能找到概率最高、质量最好的译文吗？【拓展】

**参考口答：** 不保证。有限束宽会剪掉候选，通常只是近似搜索；最大模型概率也不必然对应最高人工翻译质量。束宽和长度惩罚都需要验证，不能简单认定越大越好。

<a id="q089"></a>

### Q089｜训练、开发、测试集各有什么用途？【常见】

**参考口答：** 训练集更新参数，开发集选择超参数与解码策略，测试集用于最终评价。反复根据测试结果挑配置会造成信息泄漏和过度适配，因此模型变体最好在开发集比较，最后再按预定方案报告测试结果。

### Q090｜没有资源复现完整论文，可以先做什么？【常见】

**参考口答：** 可以先在很小的合成序列任务上验证形状、掩码、右移与损失，再在小翻译子集训练一个缩小模型。小实验用于检验实现与理解，不能作为复现原论文BLEU的证据；应明确报告数据、模型和训练预算差异。


## J｜复杂度、资源与适用边界

原文定位：§4；Table 1；涉及缓存等内容时属于实现拓展；[打开相关PDF页面](https://proceedings.neurips.cc/paper_files/paper/2017/file/3f5ee243547dee91fbd053c1c4a845aa-Paper.pdf#page=6)。

<a id="q091"></a>

### Q091｜标准全局自注意力的平方成本从哪里来？【必练】

**参考口答：** n个查询与n个键两两匹配，形成n乘n分数矩阵，注意力核心计算有O(n²d)项。显式保存各头权重时也有与n²相关的存储；这是长度增大时的重要成本来源。

<a id="q092"></a>

### Q092｜Table 1写O(1)，为什么模型不会常数时间完成？【常见】

**参考口答：** O(1)描述层内最少顺序操作数或任意两位置的最大交互路径，不是全部算术运算或真实运行时间。即使位置可以并行，仍需要计算大量位置对，也受硬件吞吐和内存限制。

<a id="q093"></a>

### Q093｜完整一层Transformer是否只有O(n²d)？【必练】

**参考口答：** 不止。还要计入QKV及输出投影，以及FFN，常见表达为O(n²d+nd²+nd·dff)。若dff与d成固定比例，可概括为O(n²d+nd²)。不能把Table 1中的注意力核心项当成完整层全部成本。

<a id="q094"></a>

### Q094｜batch、头数和长度怎样影响注意力内存？【拓展】

**参考口答：** 显式权重布局常为B乘h乘n乘n，因此固定其他量时长度加倍可能让这部分空间约增四倍。还存在激活、梯度、参数和优化器状态；实际高效实现可改变存储策略，所以不能只凭这个式子计算精确显存。

<a id="q095"></a>

### Q095｜自注意力总是比RNN计算量更小吗？【拓展】

**参考口答：** 不总是。按原文简化层类型比较，O(n²d)与O(nd²)的大小还取决于n与d，n较小时自注意力可能有优势。实际速度还取决于投影、FFN、batch、内核和硬件，不能只用一项渐近复杂度断言。

<a id="q096"></a>

### Q096｜一层就连接所有位置，是否已经解决长距离依赖？【拓展】

**参考口答：** 它缩短了可用信息路径，提供了更直接建模远距离关系的结构条件。但是否真正学会并正确使用这些关系，还取决于数据、参数、优化和任务，不能把可访问性等同于自动理解。

<a id="q097"></a>

### Q097｜全局注意力的结构偏置有什么特点？【拓展】

**参考口答：** 相较于局部卷积或逐步循环，它允许更自由的位置交互，局部结构约束较弱。这带来灵活性，也意味着需要通过位置线索和训练学习有效关系。关于数据效率的强结论还需专门实验，不能仅由结构推断。

<a id="q098"></a>

### Q098｜为什么适合GPU并行，是否只因为复杂度更小？【拓展】

**参考口答：** 重要原因是大量投影与位置匹配可写成批量矩阵乘法，能利用GPU并行计算，且减少沿序列的串行依赖。并行友好与算术总量是不同概念，更多并行性不等于在任何小规模输入上都更快。

<a id="q099"></a>

### Q099｜自回归推理中的KV缓存是什么，能否改变本文的结论？【拓展】

**参考口答：** 缓存已生成前缀的Key与Value，可以减少后续步骤重复计算。这是常见实现优化，并不消除“下一词依赖已生成前缀”的自回归顺序性，也不应不加说明地当作本文独立验证的创新。

<a id="q100"></a>

### Q100｜如果句子特别长，可以怎样改进？【拓展】

**参考口答：** 可以研究限制注意力可见范围、稀疏连接或其他高效计算方式；原文也讨论了局部受限注意力的方向。这些改动会改变信息路径、可见范围或近似误差，需要新实验，不能直接沿用原始全局注意力的全部性质。

### Q121｜目标序列没有右移，因果掩码还能防止信息泄漏吗？【基础｜优先练】

**请你作答：** 某实现把目标标签 [A, B, EOS] 原样作为解码器输入，使用包含主对角线的下三角因果掩码。请判断是否泄漏；写出正确的解码器输入、标签，以及三个有效位置分别能看见哪些输入。

<details>
<summary>参考答案与检查点（先作答，再展开）</summary>

会泄漏。第一个位置输入就是 A，却又要求预测 A；第二个位置输入 B、预测 B。包含对角线的掩码允许读取当前位置，所以仅屏蔽未来位置不能修复这个错误。

正确配对是：解码器输入 [BOS, A, B]，标签 [A, B, EOS]。三个位置可见的输入分别为 [BOS]、[BOS, A]、[BOS, A, B]。此时包含对角线是合理的：当前位置输入属于已知前缀，不是待预测标签。训练时可以并行算各位置；推理时仍要逐步生成。

检查点：同时说出“输入右移”和“屏蔽未来”，不能只答其中一个。BOS/EOS 是起始与结束标记的教学记号。

</details>

### Q125｜矩阵乘法能运行，注意力实现就一定正确吗？【进阶】
