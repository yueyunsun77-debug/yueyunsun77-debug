## 练习建议

先理解输入输出，再对照PPT练逐字稿，最后用题库检查理解。新增自测优先做 [Q121](03_老师提问136题与参考答案.md#q121)、[Q123](03_老师提问136题与参考答案.md#q123)、[Q130](03_老师提问136题与参考答案.md#q130)、[Q132](03_老师提问136题与参考答案.md#q132)、[Q134](03_老师提问136题与参考答案.md#q134)。暂时不会时，可以先展开答案理解后再复述。
