# 论文中文翻译与思维导图

## 怎么读

先沿导图看研究问题，再读架构与机制，随后看训练与实验证据。建议顺序：摘要与§1—2 → 图1与§3.1 → §3.2—3.5 → §4表1 → §5—6表2/表3 → §7。每读完一条分支，合上译文用自己的话解释一次。

## 版本与解释边界

- 英译法big结果采用会议版41.0 BLEU，不混用其他版本。
- 表2是newstest2014测试集，表3是newstest2013开发集。
- 原表2中Transformer训练成本使用跨语向合并列；译表明确说明，避免补造独立数值。
- 上传PDF未附注意力可视化附录；译文保留作者的附录指引并作说明。
- 思维导图中的因果解释边界及自查建议属于学习提示，与原文翻译分开。
