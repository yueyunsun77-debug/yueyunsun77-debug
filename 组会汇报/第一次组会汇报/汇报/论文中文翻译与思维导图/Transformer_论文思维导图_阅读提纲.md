# Transformer论文思维导图｜学习提纲

依据用户上传的NIPS 2017会议版。此文件为学习整理，不是论文正文译文。

主线：已有结构受限 → 注意力主导架构 → 配套机制与训练 → 实验证据 → 适用边界。

## 研究问题｜§1—2

### 此前是什么？

- RNN/LSTM/GRU按位置递推
- 卷积依赖局部处理与层间传播
- 注意力机制此前已经存在

### 遇到什么限制？

- 样本内部顺序依赖限制并行
- 远位置的信息传递路径较长

### 本文改变什么？

- 用注意力作为序列交互骨干
- 取消循环与卷积
- 保留编码器—解码器总体结构

## 整体架构｜§3.1

### 编码器 ×6

- 源词元 → 嵌入 + 位置编码
- 自注意力 → FFN（均含Add & Norm）
- 输出为源句各位置的表示Z

### 解码器 ×6

- 右移目标输入 + 位置编码
- 掩码自注意力 → 交叉注意力 → FFN
- 交叉注意力：Q来自解码器，K/V来自Z

### 输入与输出

- 训练：源句 + 右移真实目标 → 各位置预测
- 推理：源句 + 已生成前缀 → 下一词分布
- Linear + 词表Softmax → 解码策略选词

## 核心机制｜§3.2—3.5

### 缩放点积注意力

- softmax(QKᵀ / √dₖ)V
- Q/K决定权重，V提供汇总内容
- 缩放缓解大维度点积导致的Softmax饱和

### 多头与前馈

- base：8头，每头64维，拼接后投影
- FFN：512 → 2048 → 512，含ReLU
- 同层FFN跨位置共享，不同层参数独立

### 顺序与稳定性

- 正余弦位置编码与词嵌入相加
- 右移 + 因果掩码防止目标泄漏
- Post-LN：残差相加后做LayerNorm

## 为什么有效｜§4

### 并行性与路径

- 层内顺序操作：O(n)，降至O(1)
- 自注意力最大路径：O(1)
- 此处比较层类型，不是端到端推理速度

### 计算条件与代价

- 全局注意力核心复杂度O(n²d)
- 与循环层O(nd²)的比较依赖n和d
- 长序列可考虑局部/受限注意力

### 解释性的边界

- 作者观察到不同头的注意力模式
- 权重可帮助观察模型行为
- 理解提示：不能直接等同于因果解释

## 如何训练｜§5

### 数据与硬件

- WMT14：英德约450万句对
- 英法约3600万句；BPE/word-piece
- 8块P100；base约12小时，big约3.5天

### 优化与正则化

- Adam：β₁=.9，β₂=.98，ε=10⁻⁹
- 4000步warm-up，随后逆平方根衰减
- Dropout与标签平滑（base均为.1）

### 评测协议｜§6.1

- beam=4，长度惩罚α=.6
- base平均5个检查点，big平均20个
- 表3变体实验不做检查点平均

## 证据与边界｜§6—7

### 测试集结果｜表2

- newstest2014：big英德28.4 BLEU
- 英法41.0 BLEU（会议版，单模型领先）
- 训练FLOPs是跨论文估算，非同机速度实测

### 开发集变体｜表3

- newstest2013：单头24.9，8头25.8
- 16头25.8，32头25.4：更多头未持续更好
- 正余弦25.8，学习式25.7：结果接近

### 局限与后续方向

- 全局注意力有平方相关成本
- 原始推理仍自回归，逐步生成
- 原文展望：其他模态、局部注意力、减少串行生成

## 推荐阅读与自查顺序

1. 先读摘要、§1—2、§7：能用一句话说出研究问题和贡献。
2. 对照图1读§3.1：画出两路输入、编码器、解码器与输出；解释交叉注意力Q/K/V的来源。
3. 精读§3.2：手算一次softmax加权求和，再说明多头如何投影、拼接与输出。
4. 读§3.3—3.5：解释FFN、位置编码、右移与掩码、残差和Post-LN。
5. 读§4及表1：说明并行性、路径、计算量分别比较什么；不要把O(1)路径说成O(1)总计算量。
6. 读§5—6：区分训练设置、测试集表2和开发集表3，核对结果的比较对象。
7. 合上论文，沿导图做3分钟口述；不确定的节点回原文章节核对。

## 四个必须讲清楚的问题

- 输入输出：网络输出是词表分布；完整译文通过自回归解码产生。
- 创新归属：注意力、残差和归一化均有先前工作；本文的关键在注意力主导的完整序列转换架构。
- 创新收益：层内可并行和短路径是机制分析；BLEU与训练成本是整体模型的实验依据。
- 实验边界：开发集与测试集不可混用；注意力权重不自动构成因果证据；没有做过的复现实验不要表述成已完成。
