## 重现与校验

Python 3、Pillow、Java 21、Graphviz 2.42.4、中文字体 Noto Sans CJK SC。先按原生检查报告运行原生校验及导出，再运行：

```bash
python3 06_模型渲染图/生成模型渲染图.py --jar /path/to/plantuml-1.2026.9.jar
python3 06_模型渲染图/校验渲染图.py
```

参考样式 puml 使用 `@startdot`。PlantUML 1.2026.9 的此模式会把 SVG 替换成功能提示，因此生成脚本直接调用 Graphviz 渲染其中 DOT，为 PNG/SVG 提供同一真实图形。命令行 PlantUML 仍可生成 PNG；SVG 应使用本脚本。用例图沿用 `@startuml` 及既有图文件。

清单记录源模型、原生 ACT 导出及 24 个成果图文件的 SHA256；校验拒绝过期模型、占位 SVG、丢失的原需求 ID、接口变化及用例图变化。原始编号、doc 和接口明细见 [需求条目明细](需求条目明细.md)、[外部接口明细](外部接口明细.md)。

终点表示一次评估结束；阈值 XXX、重复 AUTO、后风窗等仍待确认。原生静态检查通过不等于所有工程行为或实车仿真均已验证。
