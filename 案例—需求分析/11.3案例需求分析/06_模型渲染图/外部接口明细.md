# 外部接口明细

BDD按参考图显示方形端口及中文角色，接口定义及特征仍以当前SysML为准。未添加参考图中的BMS、电驱或远控等不属于原三需求模型的角色。

|接口ID|接口类型|来源端口|目标端口|
|---|---|---|---|
|requestIVIToCAN|ThermalRequestInterface|IVI.requestOut|CAN.requestIn|
|requestCANToSYS|ThermalRequestInterface|CAN.requestOut|SYS.requestIn|
|statusSYSOutToCAN|ThermalStatusInterface|SYS.statusOut|CAN.statusIn|
|statusCANToIVI|ThermalStatusInterface|CAN.statusOut|IVI.statusIn|
|vehicleStateToSYS|VehicleStateInterface|VEHICLE.stateOut|SYS.vehicleStateIn|
|sensorDataToSYS|SensorDataInterface|SENSORS.dataOut|SYS.sensorDataIn|
|actuatorCommandsToHVAC|ActuatorCommandInterface|SYS.actuatorCommandOut|ACTUATORS.commandIn|
|cabinEffectsFromSYS|CabinEffectInterface|SYS.cabinEffectOut|CABIN_WINDSCREEN.effectIn|

## 端口特征

- ThermalRequestPort：heatingRequest:Boolean, autoModeRequest:Boolean, frontDefrostRequest:Boolean, frontDemistRequest:Boolean, targetTemperature:Real
- ThermalStatusPort：heatingActive:Boolean, autoModeActive:Boolean, frontDefrostActive:Boolean, frontDemistActive:Boolean
- VehicleStatePort：highVoltageAvailable:Boolean, vehicleFaultActive:Boolean, stateOfCharge:Real
- SensorDataPort：cabinTemperature:Real, ambientTemperature:Real, sunLoad:Real, heaterCoreInletTemperature:Real, ptcTemperature:Real
- ActuatorCommandPort：ptcEnable:Boolean, blowerCommand:Real, compressorRequest:Boolean, airDistributionMode:Real, recirculationRequest:Boolean
- CabinEffectPort：cabinHeatingEffect:Boolean, frontWindscreenDefrostEffect:Boolean, frontWindscreenDemistEffect:Boolean
