# 按用户两张截图修订指标表

以本次上传的“指标分析表 (1).xlsx”“指标分配表 (1).xlsx”为底稿，逐格检查；其原始数据与当前发布主表一致。两张截图作为表格结构与显示形式参考，截图业务是座椅/会议模式，不能据此替换本项目的热管理要求。

- 保留截图的八列表头及顺序，两表均为 36 条主指标，不增减指标或混入场景参数。
- “指标类型”统一显示为“属性”。原“使能条件、状态反馈”等内容是业务分类，已保留在该单元格批注；原分类未提供的记录照实记录，没有补造分类。结构化 JSON 的历史 indicator_type 字段继续保留原业务分类，Excel 在展示层映射为属性。
- 未提供的单位和初始化默认值统一显示“-”。“-”是显示占位，不是数值、字符串类型设计默认值或已确定的参数。原文件默认值均为空，因此没有照搬截图中的 true/0.1，也没有把开启条件、LO/HI、Close、0 转速等要求填成初始化默认值。
- 已有的度量范围/条件和描述原文保留，包括 SOC、16/30℃、0.5℃、50 ms、XXX、TBD、90%待定、1000 r/min待标定。截图不能推导新的热管理范围，原表“度量范围”暂兼容保存验收条件与定性约束，未将这些已知要求清空成“-”。
- 分析表第二列仍是三条需求对应的功能；分配表第二列仍是承接指标的逻辑功能。同一指标的名称、单位、范围和描述一致，是同一指标在两个归属视角的表达。
- 采用灰色表头、白底、筛选、冻结首行及前两列、自动换行与横向打印。表内不增加标题行、统计行或附加字段。描述单元格批注保留指标ID和原资料来源定位。

本轮只修改两张主表的截图显示方式、单元格批注及版式，业务阈值/条件、结构化JSON、原SysML和其他场景表不变。主表一致性校验同步采用“原分类→属性、未提供→-、空默认值→-”的显示映射；底层指标值和来源的校验哈希仍使用原值。
