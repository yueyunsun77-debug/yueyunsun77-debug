# 11.23 优化说明与版本差异

以11.17交付版为基线，按照用户确认的三个重点修改：关键行为模型补全、指标性质复核、下游导入准备。原基线压缩包保留在00_修改依据，旧版本不被覆盖。

| 项目 | 11.17 | 11.23 |
|---|---|---|
| 行为逻辑 | 大部分条件、并行、反馈在关系表中，概要活动较粗 | 六份原生SysML行为模型，199条转移，显式decide/merge/fork/join与反馈 |
| 功能粒度 | 62条记录，58项规范功能 | 原ID保留；3项组合职责细化11项子功能，共73条记录/69项规范功能 |
| 指标管理 | 41条都记作指标 | 41条全保留：8项指标、32项硬约束、1项软约束；给出逐条迁移对照 |
| 输入输出 | 概念名称及变量槽位 | 增加端口ID、概念类型引用、语义角色、已知单位与待确认状态 |
| 场景二规则 | 引用清单细化的max-valid/35℃规则 | 增加显式采用开关；未批准分支可见，不冒充既定正式策略 |
| 候选功能 | 201项候选及部分映射 | 201项逐条筛选为分析参照、暂缓或待配置确认，原证据边界保留 |
| 下游对接 | 未接入源理工具 | 准备完整导入模型集合、契约、ID映射、摘要及验收步骤；仍标未实际导入 |

指标调整不是删除条款。温度触发、SOC使能、固定工况和运行偏好即使包含数字，也不因此成为性能指标。原数值、比较符、名称/描述、缺失值和原ID保持，classification_reason记录变更依据。表格中序号间隔来自保留原ID编号，不表示遗漏。

新增功能细化只分解父功能原先已声明的职责。例如自动温控协调细化为六类调节请求；主动供风响应细化为实际条件获取、状态判断和换热量计算；电池温度/功率分别获取。没有新增未知算法、标定阈值、安全等级或故障回退策略。

三条原需求活动图以需求活动图目录为入口，三个场景模型保留在行为模型目录，避免旧概要图和新行为图成为两个并行有效版本。原阶段名称仍作为功能来源父节点和归档定位保留。
